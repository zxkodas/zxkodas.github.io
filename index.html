TickFence

Distraction blocking you can’t cheat.

A focus blocker for Windows that doesn’t rely on willpower or an app you can close. TickFence locks the programs and websites you choose until the tasks in TickTick are actually done.

  • Enforcement below the app layer Runs as a Windows service with Image File Execution Options hooks, so blocked binaries stop launching even if you kill the GUI process.
  • Real task completion Unlocks only when the mapped TickTick tasks are checked off. The fence opens on evidence, not on a timer you can cheat.
  • Websites too A companion browser extension covers the sites a process-level lock can’t reach, so the full distraction surface is covered.

irok-configurator

A launcher for the IROK web driver.

An unofficial configurator for the IROK web driver. Point it at the driver, adjust the settings the vendor’s tooling leaves buried, and get back to work without hunting through files by hand.

  • Unofficial, on purpose Built around the driver as it actually ships, without waiting on a vendor UI that covers a fraction of the available configuration.
  • Settings in one place The options buried across files and dialogs are surfaced into a single launcher so configuration is a two-minute job.
  • Native Windows A C# desktop app that feels at home on the platform it targets, instead of a web form in a wrapper.
